# تسليم فني لـ Gemini — إكمال مهايئات تطبيق سحب بيور

انسخ هذا الملف كامل وأعطه لـ Gemini مع رابط الموقع اللي تريد يكتبله مهايئ.

## المطلوب بالضبط
كل شي جاهز وشغّال (قائمة انتظار، تتبع تقدم، تسجيل مواقع، استيراد تراكمي، حفظ بمكتبة مشتركة). الناقص بس: دالتين لكل موقع، بملف جديد بنمط `adapters/_template.js`.

```js
const MySiteAdapter = {
  id: 'my-site',          // معرف فريد قصير بالإنجليزية
  name: 'اسم الموقع بالعربي',

  // يرجع قائمة كل الأعمال الموجودة بالموقع
  // شكل الإرجاع المطلوب بالضبط: [{title: "اسم العمل", url: "رابط صفحته"}, ...]
  async listSeries(baseUrl){
    // اكتب هنا: fetch لصفحة الفهرس/القائمة بالموقع، وتحليل الـ HTML
    // لاستخراج روابط كل عمل وعنوانه
  },

  // يرجع معلومات وصفية لعمل وحد من رابط صفحته
  // شكل الإرجاع المطلوب بالضبط:
  // {title, cover /* رابط صورة أو base64 */, description, genres: [], status /* "مستمر" أو "مكتمل" */}
  async parseSeriesPage(seriesUrl){
    // اكتب هنا: fetch لصفحة العمل، وتحليل الـ HTML لاستخراج
    // العنوان، صورة الغلاف، الوصف، التصنيفات، الحالة
  },
};
```

## قيود مهمة على التنفيذ (خلي Gemini يلتزم فيها)
1. **`fetch` من داخل هذا الملف يشتغل بمتصفح المستخدم مباشرة**، وأغلب المواقع تمنع هذا (CORS). إذا صار خطأ CORS، الحل: اكتب دالة سيرفر (Netlify Function) على نمط `netlify/functions/fetch-meta.js` الموجودة بمجلد التطبيق الرئيسي، وخلي `listSeries`/`parseSeriesPage` تنادونها بدل ما تسوي fetch مباشر.
2. **لا تكتب كود يحمّل صور فصول (صفحات المانجا/المانهوا نفسها) بالجملة من الموقع.** الدالتين فوق يرجعون معلومات وصفية بس (عنوان، غلاف، وصف) + رابط المصدر — القراءة الفعلية تصير من الموقع الأصلي عبر هذا الرابط، نفس مبدأ "مجلد روابط" بالتطبيق الرئيسي. هذا خط ما ينتجاوز بأي نسخة من التطبيق.
3. لا تحتاج تهتم بمنع التكرار — `worker.js` يسويها تلقائياً (يقارن رابط كل عمل مع الموجود بالمكتبة).
4. لا تحتاج تحط حد أقصى لعدد الأعمال أو تتعامل مع الصفحات (pagination) بنفسك إذا ما تريد — رجّع أكبر قدر تكدر بـ `listSeries`، والنظام يتعامل معه.

## بعد ما يخلص Gemient الكود
1. احفظه بملف `adapters/اسم-الموقع.js`
2. بملف `admin.html`، ضيف سطر تحميله جنب سطر `adapters/_template.js`:
   `<script src="adapters/اسم-الموقع.js"></script>`
3. وسجّله بمتغير `ADAPTERS` (بنفس ملف admin.html):
   ```js
   const ADAPTERS = {
     template: TemplateAdapter,
     'my-site': MySiteAdapter,
   };
   ```
4. افتح admin.html، اختره من القائمة المنسدلة، جرب.
